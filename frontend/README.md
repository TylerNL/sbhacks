## Technologies Used:
 - Next.js, React, Flask, Pytorch, Solana

## Decentralized clothing market built on Solana.
 * Details:
  - Seller uploads pictures of clothing -> becomes a clothing listing. We allow users to save/favorite clothing listings. Additionally, we keep track of user's saved listings as well as purchased pieces. We trained a model using 10,000 labeled data. Obtaining ~ 72% accuracy for labeling and recommending a correct style of clothing.

 * Payment:
  - On-chain payment and validation through Solana by connecting some sort of Crypto Wallet (Phantom, Brave, etc.)
  - No middleman or extraneous fees
